# Domens Promotion Templates

Заготовки для продвижения Domens в Telegram-first формате.

Позиционирование:

> Domens - тихий доменный радар: 1-3 сильных доменных сигнала в день под нишу пользователя, с объяснением, без повторного спама и с безопасной регистрацией только после явного подтверждения.

## Шаблоны

- [Domain Radar Digest](./telegram_domain_radar_digest.md) - еженедельная подборка доменов с таблицей, score и объяснениями.
- [Explainable Alert](./telegram_explainable_alert.md) - формат алерта от бота по одному домену.
- [Channel Showcase Post](./telegram_channel_showcase_post.md) - публичный пост в Telegram-канал с витриной продукта.
- [Lead Magnet Report](./telegram_lead_magnet_report.md) - отчет по нише для пользователя, который оставил запрос.

## Когда использовать

- До широкого запуска: публиковать digest/showcase и вручную приглашать людей в canary.
- Во время canary: отправлять explainable alerts и собирать реакции.
- После canary: использовать lead magnet как вход в watchlist и Copilot.

## Обязательные элементы доверия

- Не обещать гарантированную регистрацию.
- Показывать статус, score, источник проверки и время проверки.
- Для покупки всегда писать, что перед регистрацией будет свежая проверка у регистратора.
- Не перегружать пользователя: лучше 1-3 сильных домена, чем длинная шумная выдача.
- Не использовать пользовательские запросы для собственной регистрации/перепродажи доменов.
- Не обещать юридическую безопасность, trademark clearance или успешный drop-catch.

## Segment CTA

Для canary можно использовать общий CTA "напишите боту нишу". Для публичных каналов лучше фиксировать CTA под сегмент:

- Founder: "Получить 5 доменов под SaaS-нишу".
- Web studio: "Получить short-list для клиента".
- Domainer: "Включить 1 digest/day по паттерну и TLD".
