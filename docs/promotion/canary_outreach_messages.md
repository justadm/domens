# Canary Outreach Messages

Заготовки сообщений для закрытого набора первых пользователей и партнеров.

## Personal Founder Message

```md
Привет! Запускаю закрытый canary Domens - Telegram-first радар доменных имен.

Идея простая: ты задаешь нишу, TLD и ограничения, а бот присылает только редкие сильные сигналы, обычно 1-3 в день или меньше. Каждый алерт объясняет, почему домен попал в подборку.

Регистрация доменов сейчас в safe-mode: без явного подтверждения ничего не покупается.

Хочу дать доступ 20-50 людям и посмотреть качество сигналов. Можешь дать одну нишу, под которую тебе было бы интересно ловить домены?
```

## Web Studio Message

```md
Привет! Есть инструмент, который может быть полезен для ваших запусков и нейминга.

Domens собирает доменный short-list под нишу клиента: домен, score, статус, объяснение, риски. Не как массовый чекер, а как тихий радар с малым числом сильных вариантов.

Сейчас идет закрытый canary. Могу бесплатно прогнать 1-2 реальные ниши ваших клиентов и отдать отчет в Telegram Markdown-формате.

Если интересно, пришлите нишу, язык рынка и желательные TLD.
```

## Domain Investor Message

```md
Привет! Тестирую Domens - радар доменов, который пытается снижать шум: watchlist-first, explainable alerts, duplicate suppression, feedback buttons.

Ищу несколько людей, кто сможет оценить не "красоту интерфейса", а качество сигналов: почему домен попал в алерт, где ложные срабатывания, какие TLD/паттерны лучше скрывать.

Могу включить canary-watchlist под твою нишу с лимитом 1 digest в день.
```

## Telegram Channel Short Invite

```md
Открываем небольшой canary Domens.

Это тихий Telegram-радар доменов:

- задаете нишу и TLD;
- получаете редкие explainable alerts;
- можно нажать "больше таких", "меньше таких", "не повторять";
- регистрация отключена без явного подтверждения.

Нужны 20-50 первых пользователей.
Ответьте нишей в комментариях или напишите боту: `найди домены для {ваша ниша}`.
```

## Follow-up After First Digest

```md
Спасибо, первый digest ушел.

Нужна короткая обратная связь:

1. Был ли хотя бы один домен реально интересен?
2. Понятно ли, почему каждый домен попал в подборку?
3. Что лучше нажать по каждому варианту: "больше таких", "меньше таких" или "не повторять"?

Главная цель canary - не объем, а точность и отсутствие спама.
```

## Rejection-Safe Follow-up

```md
Понял, спасибо!

Если сейчас не актуально, я могу просто прислать один пример отчета по нише без включения постоянного watchlist. Это займет меньше минуты на просмотр и поможет понять, полезен ли формат.
```

## Notes

- Не обещать доступность или регистрацию домена.
- Не продавать "автоматическую покупку".
- Просить одну конкретную нишу, а не общий фидбек.
- После ответа сразу фиксировать нишу, TLD и лимит алертов в рабочие заметки/MemLayer.
