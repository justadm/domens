# Partner Report Template

Exportable Markdown report for web studios, branding teams, and integrators. This is the partner deliverable promised in promotion: a client-ready short-list, not a raw domain dump.

## Report Header

```md
# Domens Domain Short-list

Client/project: {client_or_project}
Niche: {niche}
Market: {market}
Prepared for: {partner_name}
Date: {date}

## Scope

We searched for domain signals matching:

- Theme: {theme}
- TLD: {tld_list}
- Max length: {max_length}
- Naming style: {style}
- Daily alert/report mode: {mode}

This report is a domain signal review, not a legal trademark clearance and not a guarantee of registration.
```

## Partner Usage Notes

- Keep the report under 5-10 domains.
- Use `provider_checked` only when the provider check is fresh.
- If confidence is `heuristic`, `stale`, `unknown`, or `rate_limited`, write cautious notes.
- Never present the report as legal approval.
- Do not include private user ids, internal event ids, confirmation tokens, or provider payloads.
