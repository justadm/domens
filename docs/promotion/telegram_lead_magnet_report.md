# Telegram Template: Lead Magnet Report

Назначение: ответ пользователю, который оставил нишу или идею продукта. Формат должен ощущаться как маленький отчет, после которого естественно включить watchlist.

## Template

```md
# Отчет Domens по нише: {niche}

Запрос: **{user_query}**

Настройки подбора:

- TLD: {tld_list}
- Максимальная длина: {max_length}
- Минимальный score: {min_score}
- Режим: {mode}

## Лучшие варианты сейчас

| Домен | Score | Статус | Почему подходит |
|---|---:|---|---|
| {domain_1} | {score_1} | {status_1} | {reason_1} |
| {domain_2} | {score_2} | {status_2} | {reason_2} |
| {domain_3} | {score_3} | {status_3} | {reason_3} |

## Что можно улучшить в запросе

- {suggestion_1}
- {suggestion_2}
- {suggestion_3}

## Следующий шаг

Я могу включить watchlist и присылать только сильные сигналы по этой нише.

Рекомендуемый лимит: **{daily_limit} алерт(а) в день**.

Команда:
`/watch add {watch_query}`

> Регистрация домена всегда требует отдельного подтверждения. Перед покупкой будет свежая проверка у регистратора.
```

## Example

```md
# Отчет Domens по нише: AI security SaaS

Запрос: **ищу домен для сервиса защиты AI-агентов**

Настройки подбора:

- TLD: .com, .io, .ai, .ru
- Максимальная длина: 14
- Минимальный score: 70
- Режим: только actionable-статусы

## Лучшие варианты сейчас

| Домен | Score | Статус | Почему подходит |
|---|---:|---|---|
| agentshield.ai | 88 | available | сильная AI/security ассоциация |
| guardflow.io | 83 | available | звучит как workflow/security tool |
| secagent.ru | 74 | available | короткий вариант под RU-рынок |

## Что можно улучшить в запросе

- Уточнить рынок: global или RU.
- Выбрать стиль: enterprise, devtool или consumer.
- Указать бюджет и допустимые TLD.

## Следующий шаг

Я могу включить watchlist и присылать только сильные сигналы по этой нише.

Рекомендуемый лимит: **1 алерт в день**.

Команда:
`/watch add AI security SaaS`

> Регистрация домена всегда требует отдельного подтверждения. Перед покупкой будет свежая проверка у регистратора.
```

## Conversion rule

Отчет должен продавать не регистрацию, а включение watchlist. Покупка домена остается вторым шагом после свежей проверки и подтверждения.
