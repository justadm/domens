# Telegram Onboarding Pack

Готовые тексты для Telegram-канала и бота Domens. Формулировки рассчитаны на мягкий canary и не обещают гарантированную регистрацию.

## Channel Name Options

1. `Domens Radar`
2. `Domens: тихий радар доменов`
3. `Domain Radar by Domens`

## Channel Bio

Short:

```md
Тихий радар доменов: 1-3 сильных сигнала под вашу нишу, с объяснением и без повторного спама.
```

Long:

```md
Domens ищет домены под нишу, TLD и ограничения пользователя. Публикуем короткие digest-подборки, объясняем score и показываем, почему домен прошел фильтр. Регистрация не гарантируется и всегда требует свежей проверки.
```

## Bot Description

```md
Domens - Telegram-first доменный радар.

Задайте нишу, TLD и ограничения. Бот будет присылать редкие explainable alerts: score, статус, причина, риск и кнопки обратной связи.

Регистрация домена не гарантируется и требует отдельного подтверждения.
```

## Pinned Channel Post

```md
# Domens - тихий радар доменов

Мы ищем не все домены подряд, а редкие сильные сигналы под конкретную нишу.

Как это работает:

1. Вы задаете нишу, TLD и ограничения.
2. Domens расширяет запрос в кандидаты.
3. Радар отсекает шум.
4. Вы получаете короткий digest или алерт с объяснением.
5. Feedback-кнопки учат радар: больше таких, меньше таких, не повторять.

Что важно:

- 1-3 сильных сигнала в день или меньше;
- без повторного same-domain спама;
- каждый алерт объясняет причину;
- регистрация отключена без явного подтверждения;
- перед покупкой нужна свежая проверка у регистратора.

CTA:

- Founder: получить 5 доменов под SaaS-нишу.
- Web studio: получить short-list для клиента.
- Domainer: включить 1 digest/day по паттерну и TLD.

Напишите боту нишу: `найди домены для AI security SaaS`.
```

## Bot `/start`

```md
Привет! Я Domens - тихий радар доменных имен.

Я могу искать домены под вашу нишу и присылать только сильные сигналы: score, статус, TLD, причину и риск.

Что можно сделать:

- `/watch add AI security SaaS` - включить watchlist;
- `/domains now AI security` - получить разовую подборку;
- `/alerts` - управлять алертами;
- `/preferences` - посмотреть правила и скрытые домены;
- `/help` - список команд.

Важно: доступность домена не гарантируется. Перед регистрацией нужна свежая проверка у регистратора. Покупка не выполняется без явного подтверждения.

Начните с команды:
`/domains now ваша ниша`
```

## Bot `/help`

```md
# Domens Help

Domens ищет домены под вашу нишу и присылает редкие объяснимые сигналы.

## Основные команды

- `/domains now <ниша>` - разовая подборка доменов.
- `/watch add <ниша>` - добавить watchlist.
- `/watch list` - показать ваши watchlist.
- `/alerts` - включить или выключить алерты.
- `/preferences` - правила, скрытые домены и настройки.
- `/profile` - ваш профиль и текущий режим.
- `/limits` - лимиты алертов.
- `/menu` - главное меню.

## Feedback

В алертах можно нажать:

- `Больше таких` - радар усилит похожий паттерн.
- `Меньше таких` - радар будет осторожнее.
- `Не повторять` - домен будет скрыт.

## Безопасность

Регистрация домена не гарантируется. Покупка требует явного подтверждения и свежей проверки доступности у регистратора.
```
