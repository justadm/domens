# Telegram Template: Channel Showcase Post

Назначение: публичный пост в Telegram-канал, который показывает продукт через кейс. Это не реклама "проверь домен", а демонстрация работы радара.

## Template

```md
# Как Domens выбирает домены

Сегодня пример из ниши: **{niche}**

Мы не отправляем все найденные варианты. Радар сначала режет шум:

- слишком длинные имена;
- слабую читаемость;
- сомнительные TLD;
- повторы по тем же корням;
- домены без понятной причины для алерта.

## Short-list

| Домен | Score | Комментарий |
|---|---:|---|
| {domain_1} | {score_1} | {comment_1} |
| {domain_2} | {score_2} | {comment_2} |
| {domain_3} | {score_3} | {comment_3} |

## Что важно

Domens работает как тихий радар:

- 1-3 сильных сигнала в день;
- объяснение "почему этот домен";
- кнопки обратной связи;
- регистрация только после явного подтверждения;
- свежая проверка перед покупкой.

Выберите сценарий:

- Founder: получить 5 доменов под SaaS-нишу.
- Web studio: получить short-list для клиента.
- Domainer: включить 1 digest/day по паттерну и TLD.

Напишите боту: `{prompt_example}`
```

## Publishing notes

- Один пост - одна ниша.
- Показывать не больше 3-5 доменов.
- Хорошо работает серия: "разбор ниши", "лучший сигнал недели", "почему домен не прошел фильтр".
