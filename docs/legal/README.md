# Legal And Trust Pack

Status: draft for closed pilot. Requires legal review before public launch.

Updated: 2026-06-16

This directory is the working legal/trust package for Domens Radar. It is not final legal advice and must not be used as an approved public contract until reviewed and filled with production details.

## Documents

- `privacy_policy_draft.md` - data categories, processing purposes, retention draft, deletion path, processors.
- `offer_agreement_draft.md` - service scope, explicit registration, prohibited use, liability draft.
- `support_and_disclaimer_draft.md` - support channels, product disclaimer, registration disclaimer, alert disclaimer.

## Public Launch Blockers

- Legal review.
- Legal entity or operator details.
- Production support contacts.
- Final retention periods.
- Final provider/processor list.
- Final no-front-running wording.
- Data deletion request path.
- Final registration disclaimer and approval gate if registration is advertised.

## Current Trust Commitments

- Telegram-first domain radar, not a broad auction/search marketplace.
- Watchlist-first monitoring during closed pilot.
- Conservative daily and per-destination alert limits.
- Explainable alerts: score, TLD, status, provider, risk, matched query.
- User feedback controls: why, more like this, less like this, never repeat.
- Registration disabled by default and always requires explicit confirmation.
- DNS reserve or DNS zone creation is not represented as domain registration.
- Search, watchlist, feedback, and alert data must not be used to front-run the user.
